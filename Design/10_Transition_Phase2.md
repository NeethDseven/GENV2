# 10 — Transition Phase 1 → Phase 2

**Statut :** canon REBORN  
**Périmètre :** *ne conçoit pas* le contenu Phase 2 — garantit la **continuité**.  
**Owner export :** `Architecture/Heritage` · **seuil :** `Projection`  
**Créatures :** `07_Creatures.md`

---

## Charte de continuité (9 lois)

1. Une mécanique prépare la suivante.  
2. Une info affichée aide une décision.  
3. Une créature est un être de collection, pas une unit de score.  
4. Les drones explorent avant les humains.  
5. L’exploration crée le besoin de construire, jamais l’inverse.  
6. Chaque bâtiment débloque une capacité scientifique.  
7. La découverte > la production.  
8. Le patrimoine = progression réelle.  
9. **La Phase 2 n’ajoute pas de règles fondamentales : elle augmente uniquement l’échelle.**

---

## 0. Principe

> La Phase 2 **ne remplace** aucune mécanique. Elle les **agrandit**.  
> Un seul jeu. Deux horizons.

```
Phase 1              Phase 2
Une planète     →    Une galaxie
5 verbes        →    5 verbes
D1–D5           →    D1–D5 + regards
Patrimoine      →    Patrimoine exposé
```

### Portable vs local

| PORTABLE | LOCAL |
|----------|--------|
| Créatures noyau, collection musée, savoir, mémoire | Layout campus, stocks, timers |
| Fiche créature (espèce, rareté, capacités, pureté) | Simulation complète berceau |
| Carte postale d’origine | Tick-par-tick stabilité |
| Réputation naissante | Staffing session |

> La base peut rester. Le patrimoine part.

## 1. Boucle inchangée

| Verbe | P1 | P2 (échelle) |
|-------|----|----------------|
| Rencontrer | Zones berceau | Mondes sauvages / sites |

---

## 2. Matrice de compétences (condensée)

| Muscle P1 | Usage P2 |
|-----------|----------|
| Fit espèce↔monde | Choisir niche de camp |
| Composition expé + drones | Tenir un camp limité |
| Analyser avant d’agir | Valeur génome / hybride |
| Muter / croiser | Licences / contrats |
| Constituer une collection | Identité sociale (bestiaire) |
| Protéger berceau | Éthique sites publics |
| Silhouette créature | Trade, alliance |
| MVE / sélection export | Patrimoine portable |

Si une compétence P1 n’a pas d’écho P2 → elle n’a rien à faire au centre du prologue.

---

## 3. MVE (rappel)

1. Collection non vide (espèces analysées + au moins une pièce remarquable)  
2. Noyau analysé  
3. Au moins une mutation ou un hybride mémorable  
4. Mémoire non vide  
5. Preuves d’épreuve (missions)  
6. Baie opérationnelle  

---

## 4. Premier voyage

**Ressent :** fierté, vertige, attachement, responsabilité, continuité.  
**Possède :** patrimoine + muscles d’explorateur — pas la ville.  
**Pas de nouveau tutoriel :** chaque action P2 a une version berceau en P1.

Cérémonie : revue patrimoine · lecture GENESIS · dernier regard berceau · projection.

---

## 5. Mondes sauvages — reconnaissance immédiate

Recon drones · carte · expé · camp temporaire · prélèvements · labo · fit · éthique site  
= **mêmes mécaniques**, autre échelle.  
Camp = **projection**, pas multi-city.

---

## 6. Commerce (chaîne)

```
Collection lisible → réputation d’Institut
    → licences biologiques → contrats → échanges de savoir
        → économie vivante
```

Pas d’AH de stats. Économie du **savoir** et du **vivant nommé**.  
**Pas** de marché de lignées / dynasties.

---

## 7. Drones & bâtiments (échelle)

| P1 | P2 |
|----|-----|
| Vol local | Orbitale / atmosphère / relais camp |
| Bureau / Labo / Vivarium / Musée / Baie | Mêmes **capacités** en camp / voyage |

Institut = cœur d’organisation, pas abandonné.

---

## 8. Le patrimoine est le personnage

Bâtiments, stocks, camps peuvent changer.  
**Créatures, collection, savoir, mémoire** accompagnent toute l’aventure.
