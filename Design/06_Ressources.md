# 06 — Ressources / Économie

**Statut :** canon REBORN  
**Principe :**

> **Une ressource est un carburant d’acte.**  
> Si elle n’alimente pas  
> `Rencontrer → Comprendre → Transformer → Éprouver → Inscrire (→ Partir)`  
> → elle sort ou devient un **état**.

**Aligné :** `00`–`05` · `Architecture/Economy` · `02` (redondances V1)

## 2. Système officiel

### 2.1 Trois monnaies d’acte

| ID | Nom | Rôle unique | Sources typiques |
|----|-----|-------------|------------------|
| R1 | **Matière organique** | Carburant des actes sur le **vivant** | Missions, sous-produits — pas harvest spam |
| R2 | **Prélèvements** | **Savoir brut** (Comprendre / forger) | Missions, préleveurs ; **grade** standard/soigné/exceptionnel ; **tags terrain** |
| R3 | **Logistique** | Ops, drones, projection | Retours faibles — pas entrepôt |

### 2.2 Instruments & agents (pas monnaies)

| | |
|--|--|
| **Parc drones** | Usure / perte / reconfig (`04`) |
| **Personnel** | Pool borné, 2–3 rôles, disponibilité |

### 2.3 États (ne se farm pas)

| État | Porte sur |
|------|-----------|
| Stabilité du berceau | Monde |
| État de l’équipe | Personnel |
| Pureté / statut | Créature (`07`) |
| Knowledge | Créature / savoir |
| Lecture de zone | Carte |

### 2.4 Wealth réelle

**Patrimoine** : créatures, collection musée, mémoire, savoir — pas les stocks R1–R3.

## 4. HUD économique

**Priorité :** patrimoine · expéditions · équipe/drones · berceau · **puis** 3 monnaies compactes.

**Disparaît :** multi-caps, moral/santé séparés, drones-gold, pureté double.

## 5. Phase 2

Mêmes 3 carburants d’acte en camp.  
Crédits / prestige chiffré = **en plus**, ne remplacent pas le patrimoine.

---

## 6. Règles canon

1. **3 monnaies d’acte max** en P1.  
2. **1 coût principal** par type d’acte (vivant vs terrain).  
3. **0 harvest** core loop.  
4. **0 prod passive** de fierté.  
5. **États ≠ monnaies.**  
6. **Patrimoine ≠ stock.**  
7. Toute nouvelle ressource doit **tuer une redondance** ou refuser d’entrer.
