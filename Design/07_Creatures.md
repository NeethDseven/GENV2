# Créatures

## Vision

Les créatures sont le cœur vivant de GENESIS. Elles ne sont pas de simples unités : elles représentent les espèces que votre empire découvre, étudie et fait évoluer.

Le plaisir vient de trois choses :

* découvrir de nouvelles espèces ;
* les améliorer grâce à la science ;
* créer des hybrides uniques.

L'objectif n'est pas de construire des arbres généalogiques complexes, mais de constituer une collection d'espèces toujours plus extraordinaires.

---

# Cycle de vie

Chaque créature suit une boucle simple :

**Explorer → Découvrir → Analyser → Évoluer → Envoyer en mission → Recommencer**

Au fil de la partie, le joueur enrichit progressivement son bestiaire et débloque de nouvelles possibilités scientifiques.

---

# Structure d'une créature

Chaque créature possède uniquement :

* un nom ;
* une espèce ;
* une rareté ;
* quelques caractéristiques principales (Force, Vitesse, Résistance, Intelligence) ;
* une ou deux capacités spéciales ;
* un niveau de pureté génétique.

C'est tout.

---

# Analyse

Lorsqu'une nouvelle espèce est découverte, elle doit être analysée au laboratoire.

L'analyse permet de :

* connaître ses caractéristiques ;
* la rendre disponible pour les missions ;
* débloquer les mutations ;
* autoriser les croisements.

---

# Mutations

Les mutations améliorent une créature existante.

Elles peuvent :

* renforcer ses caractéristiques ;
* lui donner une capacité spéciale ;
* l'adapter à un environnement particulier.

Les mutations comportent toujours une part de risque.

---

# Croisements

Deux créatures analysées peuvent être croisées.

Le résultat est une nouvelle espèce hybride qui hérite d'une partie des qualités de ses deux parents.

Chaque hybride est unique.

Exemple :

Dragon de magma
+
Esprit corallien
↓
Dracoral

Le jeu conserve simplement les deux parents à titre informatif. Il n'existe ni lignées, ni dynasties, ni transmission d'héritage.

---

# Missions

Les créatures accompagnent les expéditions.

Leurs caractéristiques influencent les chances de succès, les découvertes et les récompenses.

Une créature blessée ou épuisée sera moins efficace jusqu'à sa récupération.

---

# Musée

Le musée conserve les créatures les plus remarquables de l'empire.

Il met en valeur :

* les premières découvertes ;
* les hybrides rares ;
* les créatures les plus puissantes ;
* les espèces emblématiques.

Il s'agit d'une collection vivante, pas d'un arbre généalogique.

---

# Philosophie

Le système doit rester simple à comprendre.

Chaque nouvelle créature doit donner immédiatement envie au joueur de se demander :

> *Que se passera-t-il si je la fais évoluer ou si je la croise avec une autre ?*

Toute mécanique qui n'enrichit pas directement cette boucle de découverte, d'évolution et de création est volontairement écartée.
